# ツール工房（tool-koubou）とプロンプト作り役

VS Code の GitHub Copilot で、自分の作業を楽にする小さなツールを作るためのフォルダです。

中に「プロンプト作り役」が入っています。Copilot のチャットで選べる、決まった役目を持った Copilot（エージェント）です。作りたいもの・楽にしたい作業を一言書くと、3問ずつの質問で中身を詰めて、Copilot がそのまま作れる頼み方（プロンプト）にまとめます。質問には番号で答えるだけです。最後に、返事の下に出るボタンを押すと、Copilot が作り始めます。

AIやプログラミングに慣れていない方向けです。Copilot にいきなり「〇〇を作って」と頼むと、書いていない所を Copilot が想像で埋めて作り、「思っていたのと違う」になりがちです。先に中身を詰めて、1回目から思ったものに近づけるのがねらいです。

## 流れ

```
あなた         ：毎週の日報の集計を楽にしたい
プロンプト作り役：言い換えて確かめ、3つの質問（選択肢とおすすめつき）
あなた         ：1,2,1　（迷ったら「おまかせ」）
                 …… これを2〜3回 ……
プロンプト作り役：まとめ → OKなら、Copilotに渡すプロンプト
あなた         ：［この内容でCopilotに作らせる］ボタンを押して送る
Copilot        ：このフォルダの中にツールのフォルダを1つ作り、まず小さい版を作る
```

## 取り方

1. このページの緑の「Code」ボタン →「Download ZIP」を押します
2. ダウンロードしたZIPを右クリック →「すべて展開」で取り出します。フォルダが `tool-koubou-main\tool-koubou-main\` のように二重になるので、中の方（`.github` と `はじめに.md` が入っている方）のフォルダを `tool-koubou` という名前に変えて、場所の途中に日本語が入らない所（例：`C:\tool-koubou`）に置きます。場所に日本語が入ると、動かない道具があるためです
3. あとは [はじめに.md](はじめに.md) のとおりです。VS Code でこのフォルダを開き、チャットで「プロンプト作り役」を選ぶまでの入れ方と、使い方・困った時が書いてあります

## 用意するもの

- VS Code（1.106 以降）。版は、メニューの「ヘルプ」→「バージョン情報」で確かめられます
- GitHub Copilot が使える状態。VS Code のチャットで Copilot に話しかけて、返事が来ればOKです
- 会社のパソコンで使う時は、Copilot を仕事に使ってよいか、会社の決まりを先に確かめてください（作った人としては使ってかまいませんが、会社の決まりは別です）
